# 🌍 Global Market Performance Dashboard (Tableau)

## 📌 Overview

This project showcases a Tableau dashboard that visualizes global market performance across different regions and categories.

## 🎯 Objectives

* Compare sales performance across countries
* Identify high-performing regions
* Understand global sales distribution

## 📊 Key Insights

* Sales contribution varies significantly across regions
* A few key markets contribute the majority of revenue
* Geographic visualization helps identify performance patterns

## 🛠 Tools Used

* Tableau
* Data Visualization
